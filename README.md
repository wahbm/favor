# 有来有往

中文人情往来账本。React + Vite / Fastify / MariaDB，全栈 TypeScript，前后端同源部署。

- 每人一个私有个人账本，可创建或加入多个家庭账本。
- 家庭成员共同维护，记录可归属家庭或某位成员；个人归属的家庭记录仍在家庭内共享，不会出现在私有个人账本中。
- 人物、事由、具体事件、方向、日期、金额、经手人、备注；支持跨本人账本复用资料，同名人物用关系和说明区分。
- 按人物、事由、事件、收支、日期和归属筛选；查看人物往来与事件汇总。
- 邀请链接7天有效，可撤销；成员移除即时失权，历史归属保留。
- 以分存储人民币，使用北京时间，不接受未来日期；并发编辑带版本检查。
- CSV 导出；版本化 JSON 备份、预览和事务导入，重复记录跳过。

## 本地启动

要求 Node.js 22.12+、npm、MariaDB 10.11+（本地已验证12.3，CI配置11.4）。不需要 OpenAI API 或第三方登录服务。

1. 在本地 MariaDB 创建独立的 `utf8mb4` 数据库 `favor` 和仅可访问它的数据库用户，不要使用生产库进行开发。
2. `cp .env.example .env`，在本机编辑 `DATABASE_URL`。数据库密码中的特殊字符须进行 URL 编码；不要提交 `.env`。
3. 执行：

```sh
npm ci
npm run migrate
npm run dev
```

打开 Vite 显示的本机地址，默认 [http://localhost:5173](http://localhost:5173)。`APP_ORIGIN` 必须与浏览器实际访问的来源完全一致，不含路径。端口变化时也应同步修改。前端通过 Vite 代理 `/api` 到本机3000端口。

创建账号，系统会自动创建个人账本；侧栏可创建家庭账本，在“账本与设置”中创建邀请链接。邀请接收人登录或注册后，点击“接受邀请”。注册用户名为2–32位汉字、字母、数字、下划线或横线，密码至少10位。暂不提供自助找回密码。

构建并运行同源版本：

```sh
npm run build
# 将 .env 的 APP_ORIGIN 改为 http://localhost:3000
npm start
```

`npm start` 使用 `.env`；生产环境由 systemd 注入变量，直接运行 `node dist/server/index.js`。

## 验证

```sh
npm run typecheck
npm test
npm run build
```

未提供测试数据库时，`npm test` 运行领域单元测试并明确跳过数据库集成测试。完整验证须创建独立测试库，库名必须为 `favor_test` 或以 `favor_test_` 开头：

```sh
npm run build
TEST_DATABASE_URL='mysql://USER:PASSWORD@127.0.0.1:3306/favor_test' npm test
```

测试在指定测试库内创建隔离的测试用户与账本，不会清空已有表；不要指向真实业务库。CI 使用独立 MariaDB 服务执行完整集成测试，并生成 Linux x64 运行包。格式化源码使用 `npm run format`。

## 数据与安全规则

数据库每个连接使用 UTC，会计日期与页面时间显示使用北京时间。金额为正整数分，方向决定收支；差额为收入减支出，并非债务。只支持1900年以来的日期。

所有账本数据接口均在服务端检查成员权限，写入和成员移除通过事务锁串行处理。人物、事由和事件可从本人有权访问的其他账本复用；这些候选资料仅对当前登录者展示，不会自动公开给目标家庭。保存记录时，所选资料才事务复制到当前账本，失败则整批回滚。各账本资料独立维护，不自动同步后续修改，也不会复制收支记录。记录包含创建人、最近修改人、时间和版本号，编辑冲突时返回409，避免覆盖别人修改。

密码采用 Argon2id 哈希，会话保存在数据库，Cookie 为 HttpOnly / SameSite=Lax，生产环境启用 Secure。会话14天到期，登录及注册限流；写请求验证 Origin 和会话 CSRF 令牌。密码修改使旧会话失效。生产环境强制 HTTPS 来源。后端日志不记录邀请链接查询参数。

JSON备份格式为 `format: favor, version: 1, records: [...]`。备份只有记录及关联人物、事由、事件信息，不含密码、会话、邀请、成员权限或空的未使用字典。导入仅追加，不覆盖现有记录；人物以稳定来源ID区分，允许同名。已导入或已删除的来源记录不会被同一备份再次恢复。若确实需要从旧备份回滚误删或修改，请采用管理员数据库恢复流程，而不是追加导入。

个人账本导入将个人记录归属当前本人，不接受家庭归属记录。家庭导入按用户名匹配已存在于本账本的成员，支持已退出成员的历史归属；缺少成员时整批拒绝。不会通过导入创建账号或授予访问权。备份文件最大8MB、每次最多10,000条记录；预览与确认均重新完整校验，确认失败会整体回滚。

CSV 仅导出当前筛选结果（设置页导出全部），以元显示金额，并转义公式开头内容，降低电子表格公式注入风险。

## 阿里云部署

生产入口为 [人情账本](https://8.130.116.192/mosshqq/favor/)，发布流程见 [部署与恢复说明](deploy/README.md)。前端构建通过 `PUBLIC_BASE_PATH` 指定基础路径，后端 `BASE_PATH` 必须与之匹配（不含尾斜杠）。Nginx去掉此前缀后将请求转发给应用。默认本地开发仍使用根路径。

当前未实现：账本删除、所有权转让、跨账本合并、实物礼品、未来计划、自动回礼匹配和自助密码找回。记录列表按账本加载，适合个人和小规模家庭使用；后续大数据量场景应增加服务端分页和数据库聚合。
